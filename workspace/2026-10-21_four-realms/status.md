# Four Realms: Awakening

Browser-first elemental arena prototype. Source and startup instructions are in
`projects/four-realms/README.md` in this repository.

Implemented: reference-art main menu, four elements, third-person arena, training,
private two-player rooms, server-authoritative combat and rematches.

The concept art is the visual target. Runtime arena geometry and characters are
stylized placeholders, not a match for the photorealistic reference images.
Multiplayer needs the included persistent Node server; no public deployment has
been created. See the project's verification record before publishing claims.
